# 📘 Repositório de Estudos em C

Este repositório reúne códigos, exercícios e pequenos projetos desenvolvidos na linguagem **C**. O objetivo principal é servir como material de estudo, revisão e prática de lógica de programação para a faculdade de Engenharia de Software.

## 📂 Estrutura do Projeto

O repositório está organizado em pastas e arquivos individuais, cobrindo desde conceitos básicos até implementações mais interativas:

### 🎮 Projetos e Jogos
- **`Jogo da velha/`**: Implementação do clássico jogo da velha (Tic-Tac-Toe).
- **`jogadorXjogador.c`**: Lógica para partidas entre dois jogadores (PvP).

### 📚 Listas de Exercícios
- **`50 exercicios/`**: Uma coleção abrangente de exercícios para praticar sintaxe, laços de repetição e condicionais.

### 🛠️ Conceitos e Utilitários
- **`file.c`**: Exemplos de manipulação e leitura de arquivos em C.
- **`randSrand.c`**: Demonstração de geração de números aleatórios utilizando `rand()` e `srand()`.
- **`LengthEmC.c`**: Estudos sobre cálculo de tamanho de dados/strings.
- **`ajudaPolly.c`**: Script auxiliar de resolução de problemas específicos.
